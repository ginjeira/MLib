# Документация

[Spotygram](../README.ru.md) · [English](README.md) · **Русский**

MLib — независимая ветка разработки. Руководства пользователя и архитектуры ниже унаследованы от Spotygram и пока не являются проверенной документацией пользователя MLib. Руководство по сборке описывает текущий процесс разработки MLib.

| Руководство | Что внутри |
| --- | --- |
| [Унаследованное руководство Spotygram](usage.ru.md) | Справка по исходным функциям входа, плейлистам, офлайн-файлам и плееру; ещё не проверено для MLib |
| [Сборка и выпуск](build.ru.md) | Инструменты, API-данные, подпись пакетов и релизы на GitHub |
| [Устройство приложения](architecture.ru.md) | Работа с Telegram, библиотека, воспроизведение и проверка обновлений |
| [Журнал проверок](verification.ru.md) | Что проверено на практике, каким способом и что ещё не проверялось |
| [Сторонние компоненты](third-party.ru.md) | Зависимости и лицензии |

У каждого руководства есть переключатель языка. Английская версия использует
обычное имя файла; перевод добавляет код языка перед `.md`: `usage.ru.md`,
`usage.ua.md` и так далее. Для нового языка переведи пять руководств и обе входные
страницы, затем добавь ссылки в их навигацию. Темы и актуальные факты должны
совпадать; формулировки могут отличаться. Переводы интерфейса хранятся отдельно в XML.

Production-релизов MLib пока нет. Не используйте APK Spotygram как установщик MLib. Будущие сборки MLib будут опубликованы на [странице релизов MLib](https://github.com/ginjeira/MLib/releases).
Подробные материалы прежних проверок доступны в исходниках по тегам;
ссылки находятся в журнале проверок.
